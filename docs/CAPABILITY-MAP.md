# Mapa de capacidades: LOH ZUPRIMILLO'

| Módulo | Responsabilidad | Depende de |
|---|---|---|
| identity | Whitelist, invitaciones, contraseñas, sesiones y roles | — |
| media | Subida y entrega privada desde R2 | identity |
| social | Publicaciones, comentarios, reacciones, perfiles y búsqueda | identity, media |

| games | Encuestas, clips, batallas, preguntas, XP, logros y premios | social |

Orden: identity → media → social → lore y games → operations.
